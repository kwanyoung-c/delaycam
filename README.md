# 딜레이 카메라 (Delay Camera)

체육 수업과 운동 자세 교정을 위한 모바일 웹앱입니다. 동작을 하고 나서 몇 초 늦게 재생되는 화면으로 자기 자세를 바로 확인할 수 있습니다.
빌드 과정이 없는 순수 정적 사이트(HTML/CSS/JS)라서 GitHub Pages에 그대로 올리면 됩니다.

## 기능
- **지연 재생**: 0(실시간)·1·2·3·5·7·10·15·20·30초
- **전면/후면 카메라 전환**: 전환해도 기록(버퍼)은 그대로 유지됩니다. 전면 카메라는 거울 모드를 켜고 끌 수 있습니다.
- **재생 속도**: ¼x · ½x · 1x · 2x (슬로모션을 쓰면 지연 시간이 늘어나고, **LIVE** 버튼을 누르면 설정한 지연으로 돌아옵니다)
- **구간 반복**: **A**(시작점)·**B**(끝점)를 누르면 그 구간만 반복 재생합니다. A, B, 반복 버튼 중 하나를 길게 누르면 구간이 해제됩니다.
- **타임라인**: 끌어서 되감기, 이전/다음 프레임 단위 이동
- **기록 정지**: 버퍼를 고정해 두고 지나간 동작을 천천히 분석합니다.
- 화면 꺼짐 방지(Wake Lock), 홈 화면 추가(PWA), 오프라인 실행

## 화면 방향 처리 방식
- 기기를 물리적으로 돌려도 화면이 바뀌지 않고, **회전 버튼을 눌렀을 때만** 세로/가로가 바뀝니다.
  - 매 프레임마다 시스템 회전 각도(`window.orientation` / `screen.orientation.angle`)를 확인하고, 루트 레이아웃을 그 반대 방향으로 CSS 회전시켜 앱이 고른 방향을 유지합니다. 그래서 자동 회전이 켜져 있어도, 꺼져 있어도 똑같이 동작합니다.
  - Android에서 전체화면(설정 → 전체화면)을 쓰거나 홈 화면에 추가하면 `screen.orientation.lock()`으로 시스템 차원에서도 방향을 잠급니다.
- 카메라 프레임은 **기기 기준 방향으로 정규화**해서 저장합니다. 그래서 시스템이 카메라 영상을 돌려도 버퍼가 초기화되지 않고, 화면에 그릴 때 현재 앱 방향에 맞춰 회전합니다. 비율은 유지되며(`cover`, 설정에서 `contain`으로 변경 가능) 찌그러지지 않습니다.
- 화면 방향을 바꿔도 카메라 연결과 버퍼는 그대로 유지됩니다(카메라를 다시 열지 않습니다).
- 컨트롤 배치: 세로 모드에서는 영상 아래, 가로 모드에서는 화면 옆에 놓입니다. 열 개수는 화면 크기에 맞춰 자동으로 계산되므로 버튼이 겹치지 않습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다(예: `delay-camera`).
2. 이 폴더의 파일을 전부 저장소 루트에 올립니다(`.nojekyll` 포함).
   ```bash
   git init
   git add .
   git commit -m "딜레이 카메라"
   git branch -M main
   git remote add origin https://github.com/<아이디>/delay-camera.git
   git push -u origin main
   ```
3. 저장소에서 **Settings → Pages → Build and deployment**로 가서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 설정합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/delay-camera/`에 접속합니다.

> 카메라는 **HTTPS**에서만 동작합니다. GitHub Pages는 기본으로 HTTPS를 제공합니다. 로컬에서 테스트할 때는 `python3 -m http.server`를 실행하고 `http://localhost:8000`으로 접속하세요(localhost는 예외로 허용됩니다).
> 수정한 내용을 배포한 뒤에도 예전 화면이 보이면 `sw.js`의 `CACHE` 버전(`delaycam-v1` → `v2`)을 올려 주세요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 레이아웃(세로/가로), 디자인 |
| `app.js` | 카메라, 버퍼, 재생, 방향 고정 로직 |
| `manifest.webmanifest`, `icons/` | 홈 화면 추가(PWA) |
| `sw.js` | 오프라인 캐시 |

## 참고
- 기록 길이와 화질에 따라 메모리를 사용합니다(최대 약 180MB로 제한). 오래된 기기에서는 설정에서 화질을 '저', 프레임을 24로 낮추세요.
- iPhone Safari는 웹페이지의 전체화면과 방향 잠금을 지원하지 않습니다. 이 경우에도 CSS 보정으로 화면은 고정되지만, 기기를 돌리는 순간 시스템 회전 애니메이션이 잠깐 보였다가 바로 원래 방향으로 돌아옵니다. 제어 센터에서 '화면 방향 잠금'을 켜 두면 가장 매끄럽습니다.
